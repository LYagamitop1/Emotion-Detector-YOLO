# Emotion Detector YOLO

## This Emotion detector can detect over 9 different emotions:
## Natural, Happy, Sad, Sleepy, Surprised, Angry, Contempt, Disgust, Fear

## I trained a yolo model using dataset of over 1,00,000 images of peoples showing these emotions. 

## It took about 12 Hours to complete 50 epochs for the training of nano model of yolo using Nvidia Tesla T4 x2 GPU.
